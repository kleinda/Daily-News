# 📰 התקציר היומי – סוכן חדשות

כל יום ב־08:00 הסוכן אוסף ידיעות מהמקורות, מסנן ספורט, ובוחר 10 ידיעות לכל קטגוריה:
🇮🇱 בארץ · 🌍 בעולם · 🌟 רכילות.

| קובץ | תפקיד |
|---|---|
| `agent.py` | הסוכן: איסוף RSS, סינון ספורט וכפילויות, בחירה וסיכום. כותב `news-data.js` ו־`data/news.json` |
| `index.html` | האתר: 3 לשוניות, תאריך ושעה לפי שעון ישראל, כפתור רענון |
| `server.py` | שרת מקומי: מגיש את האתר ב־http://localhost:8000, מריץ את הסוכן ב־08:00 ומהכפתור |
| `config.json` | הגדרות: `use_claude` – שימוש ב־Claude לסיכומים (כבוי כברירת מחדל) |
| `start-news.bat` | הפעלת האתר בלחיצה כפולה |
| `install-schedule.ps1` | רישום ב־Task Scheduler: סוכן כל יום ב־08:00, ושרת שעולה בכניסה ל־Windows |

## הפעלה
```
python server.py                                            # הרצה ידנית ופתיחת האתר
powershell -ExecutionPolicy Bypass -File install-schedule.ps1   # הפעלה אוטומטית קבועה
```

## סיכומים חכמים עם Claude (כבוי כברירת מחדל)
כברירת מחדל מוצגים הכותרת והתקציר כפי שהופיעו במקור, בלי שימוש במפתח API.
כשהאפשרות פעילה, Claude בוחר את הידיעות החשובות, מנסח כותרת תמצית וסיכום קצר וקולע בעברית
(כולל תרגום ידיעות מ־BBC ו־Guardian), ומתאים אייקון לכל ידיעה. השימוש ב־API מחויב בנפרד מהמנוי ל־Claude.

להפעלה:
1. להגדיר מפתח פעם אחת: `setx ANTHROPIC_API_KEY "sk-ant-..."`
2. לשנות ב־`config.json` ל־`"use_claude": true`

לכיבוי מחזירים ל־`false`. השינוי חל מהרענון הבא, בלי להפעיל מחדש את השרת.

## כרטיסי אנשים ברכילות
בלשונית הרכילות, שמות של אנשים בכותרות הם קישורים. לחיצה פותחת חלון עם תמונה ותיאור קצר
מוויקיפדיה העברית, וקישור לערך המלא. השמות מזוהים אוטומטית: רק ערכים שמוגדרים ב־Wikidata כבני אדם
(כך "הצל" או "ראש הממשלה" לא יסומנו בטעות). מי שאין לו ערך בוויקיפדיה – לא יסומן.
